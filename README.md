# APS Concept V7 | Groundwork

A standalone, light-first design concept for APS Land Services. This is not a continuation of the V1–V6 visual design.

## Structure
- `index.html`, `services.html`, `about.html`, `contact.html`
- `css/site.css`
- `js/site.js`, `js/us-map.js` (original map logic retained)
- `assets/branding`, `assets/people`, `assets/favicons`

## Important
- Content is freshly written from previously supplied APS source material. All operational claims should be reviewed with APS before publication.
- The client marquee uses historical names. Only selected names have outbound links; verify URLs and permissions/relationship framing before publishing.
- The intake form opens the visitor's email client and **does not submit directly to a server**.
- The illustration on the homepage is a conceptual, not an actual GIS deliverable.
- No stock media or tracking scripts are used.
- `sitemap.xml` and canonical URLs assume clean Cloudflare routes (`/services`, `/about`, `/contact`). Confirm routing and redirects before launch.
- Development prototype: browser, accessibility, and email handoff testing remain necessary.
